Starting this site

26 August 2026

This site is plain HTML, CSS, and about a hundred lines of JavaScript for the theme picker. No static site generator, no build step, no dependencies to update. I write a file, push it, and it is live.

Adding a post

Two steps, both by hand:

  1. Copy blog/hello-world.html to blog/your-post.html and rewrite the <h1>, the <time>, and the body.
  2. Add one <li> to the list in blog/index.html pointing at it.

Then git add . && git commit -m "new post" && git push. GitHub Pages picks it up within a minute.
